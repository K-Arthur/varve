# Strata Trademark Usage Policy

"Strata" is a trademark of K-Arthur (Strata Founder). The Strata logo,
wordmark, and product icons are also protected as trademarks.

This policy governs how you may refer to Strata and use its branding.

## Permitted without permission

- Accurate, factual references to Strata in text (e.g., "compatible with
  Strata," "based on Strata", "a plugin for Strata")
- Use in personal or non-commercial projects that are not distributed to
  others
- Use in educational materials describing the software
- Reference in news articles, blog posts, or reviews

## Requiring permission

- Using the Strata name or logo in a commercial product name
- Using the Strata logo as part of your own brand, product identity, or
  company logo
- Creating domain names containing "strata" related to design software
- Using Strata branding in advertising or promotional materials

## Prohibited

- Modified builds branded as "Strata" or using Strata logos
- Implying official endorsement, affiliation, or certification without
  written agreement
- Using the Strata mark in a way that causes confusion with the official
  product
- Registering the Strata name as a trademark, domain name, or social media
  handle for competing products

## Community plugins

- May reference Strata in their description (e.g., "My Plugin for Strata")
- May not use the Strata logo as their own logo
- May not use "Strata" as their primary product name

## Modified builds (forks)

- Must remove or replace all Strata branding (name, logos, wordmarks, icons)
- Must not imply they are official Strata releases
- Must clearly state they are modified versions

## Questions?

Open an issue in the Strata repository or start a discussion.
