### Critical Gaps Identified

#### P0 — Broken Filters (schema mismatch)
1. **SelectiveColor filter**: FilterIR has `{colorRange, cyan, magenta, yellow, black, relative}` but `applySelectiveColor()` expects `{params: SelectiveColorParams[]}` → silent no-op
2. **ColorBalance filter**: FilterIR has `{cyanRed, magentaGreen, yellowBlue}` objects but software engine expects `[n,n,n]` tuples → always defaults
3. **ChannelMixer filter**: FilterIR has `{outputChannel, redPercent, greenPercent, bluePercent, constant}` but software engine expects `{red: [n,n,n], green: [n,n,n], blue: [n,n,n]}` → always defaults
4. **PhotoFilter filter**: FilterIR `color: [r,g,b,a]` tuple but software expects `{r,g,b,a}` object → always defaults

## Summary of Changes

### 1. P0 Filter Schema Fixes (`filterCompositor.ts`)
- **selectiveColor**: Added proper conversion from FilterIR single-param format to `SelectiveColorParams[]` with colorRange→color mapping and relative→method conversion
- **colorBalance**: Added `{cyanRed,magentaGreen,yellowBlue}`→`[n,n,n]` triplet bridge
- **channelMixer**: Added single-output-channel → all-3-channels conversion with switch on outputChannel
- **photoFilter**: Added `[r,g,b,a]` tuple → `{r,g,b,a}` object conversion
- **Tests**: 4 new integration tests validating each filter's bridge code

### 2. Vector Mesh & Envelope Warping (`meshWarp.ts`)
- `MeshWarp` type (cols, rows, vertices[])
- `MeshControlPoint` type
- `createFlatMesh(cols, rows, w, h)` — flat undeformed mesh
- `meshTriangles(mesh, srcW, srcH)` — triangle enumeration with source/dest pairs
- `warpMesh(src, mesh, ...)` — barycentric pixel displacement with spatial index acceleration
- **Tests**: 9 tests (createFlatMesh, meshTriangles, warpMesh correctness/stress/edge cases)

### 3. Path Offset Operations (`pathOffset.ts`)
- `offsetPath(points, closed, distance, joinStyle)` — Minkowski-sum path expansion/contraction
- `expandStroke(points, closed, widths, capStyle)` — variable-width stroke→filled outline
- `roundCorners(points, closed, radius)` — parametric corner rounding
- **Tests**: 12 tests (line offset, rect offset in/out, stroke expansion, corner rounding)

### 4. Rust Effects Parity
- `BlendMode` enum: 19 typed variants (was `String`)
- `EngineColor` enum: 4 tagged variants (was `[u8; 4]` byte array)
- Updated all color fields in `Effect`, `Stroke`, `FillIR`, `SceneNode`, `RenderItem`
- Added backward-compat deserialization for old format in strata-bridge
- 179/179 Rust tests pass, clippy clean

### 5. ImageCache LRU Fix
- Changed eviction from `Map.keys().next()` (FIFO) to `accessTimes`-based (true LRU)

### 6. L*C*h* Blend Mode Wiring
- `blendNonSeparable()` now accepts optional `method: 'w3c' | 'lch'` parameter
- `clipColor` clamping fixed (was missing upper bound)

### 7. Halftone cross/circle Pattern Rendering
- Added `cross` and `circle` dot shape matrix generation to `generateAMMatrix()`

### Data Flow
```
SceneNode.filters (FilterIR[])
  → engine.ts shapeToPrimitive → RenderItem.filters (FilterIR[])
  → replay.ts replayIr() → applyFilterWithCompositing()
    → CSS-compatible filter: ctx.filter = filterChainToCss()
    → Complex filter: snapshot → applySoftwareFilter() → composite back
      → curves.ts / levels.ts / selectiveColor.ts / ...
```

### Schema Fix Strategy
For the 4 broken filters, I'll **normalize the FilterIR type schema** to match what the software engines actually consume. This means updating `types.ts` FilterIR definitions for:
- `selectiveColor`: add `params: SelectiveColorParams[]` field
- `colorBalance`: restructure to match software engine tuples
- `channelMixer`: restructure to match software engine arrays  
- `photoFilter`: change color format from tuple to object

Then update `adjustmentToFilter()` in `filters.ts` to emit the corrected schema.
