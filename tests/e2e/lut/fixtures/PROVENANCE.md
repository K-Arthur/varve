# LUT fixtures — provenance

## Summary

Cube-format 3D LUT (Look-Up Table) files for colour-grading E2E tests.
All files are hand-authored text data derived from standard colour-grading
recipes.

| File | Description |
|------|-------------|
| `identity.cube` | Identity LUT (no-op transform) |
| `warm-shift.cube` | Warm colour temperature shift |
| `cool-shift.cube` | Cool colour temperature shift |
| `warm-look.cube` | Warm film look |
| `contrast-boost-1d.cube` | 1D contrast enhancement |
