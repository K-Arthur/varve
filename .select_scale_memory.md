## Compaction markers

- Selection box math: `M_box = T(center) · R(θ) · S(w, h)`.
- Delta matrix: `Δ = M_new · M_old⁻¹` (maps old world points to new world points).
- New node world transform: `M_new = Δ · M_initial`.
- New local transform: `M_local = M_parent⁻¹ · M_new`.
- Vector commit: decompose `M_local` into `T · R · S`, set `transform = T`, `rotation = θ`, scale shape geometry by `S`.
- Raster commit: keep `transform = T · S`, `rotation = θ` (image fill rendered under transform, no bitmap resampling).

## Research notes

- Figma: `relativeTransform` carries rotation/translation, `width`/`height` are separate (vector geometry baked).
- Konva / pixi-transformer: single delta matrix from old selection box to new selection box, applied uniformly to all selected nodes.
- Excalidraw: two-phase hit-test (rotated-AABB reject, then precise shape/path test).
- Bezier hit-test: flatten to line segments + ray-cast / point-to-segment distance.
