# Color System Memory — Session 2026-07-08

## System State
- **Canonical type:** `ManagedColor` (discriminated union: RgbColor | CmykColor | GrayColor | SpotColorRef)
- **Legacy type:** `Color` = `readonly [number, number, number, number]` (sRGB 0-255)
- **Engine mirror:** `EngineColor` (same union, self-contained)
- **Rust mirror:** `[u8; 4]` flat array
- **Fills:** Solid | Gradient | Image | Pattern (each with opacity/blendMode/visible)
- **Gradients:** Linear | Radial | Angular | Diamond (now with `tilingMode: none|repeat|reflect`)
- **Interpolation spaces:** sRGB | OKLab | OKLCH | HSL (all implemented in `colorInterpolation.ts`)
- **Color conversion:** Full pipeline sRGB↔linear↔XYZ↔Lab↔Oklab↔CMYK in `colorConversion.ts`
- **Palette extraction:** Median-cut quantization + harmony generation in `paletteExtractor.ts`
- **WCAG contrast:** Implemented in `contrast.ts` (UI component)
- **Gradient tiling:** FULLY INTEGRATED — types, rendering (OffscreenCanvas pattern), UI (GradientEditor tiling dropdown)
- **Color blindness simulation:** WIRED — per-pixel canvas overlay, View menu shortcuts (Ctrl+Alt+P/D/T)
- **ASE/GPL/ACO import/export:** Implemented — `paletteFormats.ts` with binary ASE parser + text GPL/ACO parsers
- **CSS color parser:** Implemented — `cssColorParser.ts` handles hex/rgba/hsl/oklch/oklab/named colors
- **Canvas gradient handles:** Implemented — `GradientHandleOverlay` with draggable start/end/stop handles

## Completed (2026-07-08)
### Type Definitions
- `GradientTilingMode = 'none' | 'repeat' | 'reflect'` added to scene and engine types
- `tilingMode?: GradientTilingMode` added to GradientFill, EngineGradientFill, FillIR.gradient, and Rust GradientFill/FillIR
- `midpoint` field added to Rust GradientStop (was already in TS)

### Gradient Rendering (repeat/reflect)
- `paintTiledGradientFill()` function in replay.ts — OffscreenCanvas-based pattern generation
- For 'repeat': creates repeating pattern from [0,1] gradient tile
- For 'reflect': creates mirrored 2x tile (forward + mirrored) and repeats
- Graceful fallback to standard gradient when OffscreenCanvas unavailable
- 3 new tests: repeat, reflect, undefined → standard path

### GradientEditor UI
- Tiling mode dropdown: None / Repeat / Reflect
- Midpoint range slider per stop (0-1, step 0.05)
- Pre-existing 'midpoint' field was already fully wired in interpolation engine, just needed UI

### Color Blindness Simulation
- `ColorBlindnessOverlay` component — OffscreenCanvas pixel manipulation
- Per-pixel protanopia/deuteranopia/tritanopia via Machado 2009 LMS matrices
- `colorBlindnessView` in EditorState (none | protanopia | deuteranopia | tritanopia)
- Shortcuts: Ctrl+Alt+0 (none), Ctrl+Alt+P (protanopia), Ctrl+Alt+D (deuteranopia), Ctrl+Alt+T (tritanopia)
- View menu submenu with radio items

### Swatch Import/Export (ASE + CSS parser)
- `parseAsePalette()` — full Adobe Swatch Exchange binary parser (RGB/CMYK/LAB/Gray, groups, names)
- `parseGplPalette()` / `exportGplPalette()` — GIMP palette format
- `parseAcoPalette()` / `exportAcoPalette()` — Adobe Color Swatch v1/v2
- `cssStringToManagedColor()` — robust CSS color parser (hex, rgb, hsl, oklch, oklab, named)
- `managedColorToCssString()` — reverse conversion
- All exported from @strata/shared

### Canvas Gradient Handle Overlay
- `GradientHandleOverlay` SVG component — rendered on top of canvas
- Shows gradient direction line + draggable start/end handles
- Stop position markers along gradient line (with midpoint indicator dot)
- Radial gradient shows radius circle indicator
- Drag end handle updates gradient rotation in real-time
- Uses `updateSelectedFillAt` to push changes through editor context
