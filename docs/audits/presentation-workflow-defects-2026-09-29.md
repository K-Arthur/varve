# Presentation workflow defect matrix — 2026-09-29

This matrix distinguishes directly reproduced baseline behavior from risks
reported in other products. Recheck each row as the implementation lands; a
source report is not presented as a Varve defect.

| ID | Scope | Baseline / reported failure | Status and source date | Varve acceptance scenario |
|---|---|---|---|---|
| P-01 | Varve preview UI | Existing single-frame preview leaves Layers and Inspector dock headers over the audience slide. | Reproduced locally; top-layer audience dialog passes viewport-bounds and Exit checks in browser, 2026-09-29. | Inspect audience imagery at desktop/tablet sizes and confirm focus restoration. |
| P-02 | Varve authoring | Frames had no persisted deck order, titles, notes, sections or skip state. | 12-slide save/reopen now passes with no orphan warnings after duplicate-frame ownership was fixed. A populated 100-slide deck also opens and navigates in browser, 2026-09-29. | Reopen ordered deck with notes/skip/section intact and no orphaned scene nodes; stress-test remains hardware-specific. |
| P-03 | Varve output | Export flow has no sequence-level deck PDF or ordered PNG archive. | Populated browser journey wrote a 3-page raster PDF and ZIP with `01-A-better-story.png`, `02-The-sequence.png`, `03-Local-work.png` in order. `pdfinfo`, `unzip -l`, and full-size slide inspection passed, 2026-09-29. Cancellation/write-error outcomes still need targeted checks. | Confirm PDF page count/order and ZIP entry names/order against included frames; cancellation and write errors do not report success. |
| P-04 | Varve fidelity | Existing preview thumbnail and node export paths do not guarantee exact frame-local clipping and transform parity. | Three populated text/shape/background slides now look consistent between audience preview, PNG ZIP and `pdftoppm`-rendered PDF. This fixture has no images, masks, or effects; those remain unverified, 2026-09-29. | Per-slide comparison across editor, thumbnail, audience preview, reopened file and raster outputs, including mask/effect/crop/background fixtures. |
| P-05 | Other product: layout revision | Figma Slides user reported rebuilding 25 imported slides because layout could not be changed; support supplied a new-slide workaround and forwarded a feature request. | Report dated 2025-11-05; follow-ups through 2026-07-07. Forum “Solved” marker does not document feature delivery. Varve now has geometry-only preview/reapply with role mapping; built-in layouts and formatting/themes remain incomplete. | Existing populated slide accepts a previewed layout revision while preserving content, identities, notes, overrides and extras. |
| P-06 | Other product: PPTX rendering | User reported missing backgrounds/shapes; support observed a mask issue but did not reproduce rounded rectangle loss. | Report 2025-07-13; support response 2025-07-14; no resolution recorded in thread. | Rasterized core output is checked against actual rendered slide appearance; PPTX is not promised before feasibility/fidelity review. |
| P-07 | Other product: export availability | Figma Slides export was temporarily unavailable; support reported a fix and author confirmed restart restored it. A later individual-asset report was attributed to using the Slides rather than Design mode. | Incident 2026-04-01, confirmation 2026-04-02, mode clarification 2026-04-17. | In Varve, sequence export is explicit and separate from per-object export; save/cancel/error states are actionable. |
| P-08 | Accessibility | Drag-only reordering would exclude users who cannot perform precise pointer dragging. | WCAG 2.2 SC 2.5.7 guidance checked 2026-09-29; high-contrast 1200×750 touch test reorders two slides by tap. | Visible earlier/later/to-position controls work with mouse, touch and keyboard. |
| P-09 | Varve quality checks | A slide can contain placeholder-looking text, very small text, obvious shape overflow, or no separate slide description without a deck-level way to find it. | Initial advisory preflight added in the source build, 2026-09-29; contrast, font/image readiness and nested/effect bounds remain unverified. | Run checks on a deck with each condition, focus the referenced layer, and confirm only a missing included frame blocks delivery. |
| P-10 | Varve preview rendering | The audience stage sized its grid row from the slide image itself, so the image overflowed and `overflow: hidden` cropped the bottom of the slide during playback while export stayed correct. | Reproduced by geometry measurement in the running app (image box 705.25px against a 679.5px stage) and by pixel-scanning the captured slide, 2026-09-29. Fixed by sizing the stage area explicitly; guarded by an E2E assertion on containment and aspect ratio. | Measure the laid-out slide box against its stage at a mismatched viewport, and confirm the preview raster equals the delivered raster. |
| P-11 | Varve presentation mode | Deck playback and prototype playback are both called Present, and deck preview was reachable only from the Slides panel, so the menubar and shortcut could mean something different from the panel button. | Reproduced by driving the shortcut and the palette, 2026-09-29. Routed through one decision point; deck commands registered in the palette. | Press Present on a deck document, a prototype-only document, and an all-skipped deck; each behaves as documented. |
| P-12 | Varve preview input | Space did not advance, Escape did not exit, and navigation wrapped from the last slide back to the first with no indication that the deck had ended. | Reproduced with real key events, 2026-09-29. Space/Enter advance, Escape exits, and each end stops with an announcement; Previous/Next disable at the ends. | Drive Space, arrows, Home/End and Escape in playback and read the live-region announcement at each boundary. |
| P-13 | Varve preview versus delivery | Nothing proved that what an audience sees is what the file contains; a screenshot of each was the only evidence available. | Added a cross-surface check that decodes the preview raster and the delivered PNG for the same slide and compares pixels, plus every delivered page's declared size, 2026-09-29. | Compare editor, thumbnail, preview, reopened document and delivered file for one slide; pixel digests must match for preview and delivery. |
